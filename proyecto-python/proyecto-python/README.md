# Hola Python

Un script simple en Python para dar una bienvenida básica por consola.

## Requisitos

* **Python 3.x** instalado en tu sistema.

## Uso

1. **Crea el archivo**:
	Guarda el código en un archivo llamado `saludo.py`.

2. **Ejecuta el programa**:
	Abre tu terminal o consola y ejecuta el siguiente comando:
	```bash
	python saludo.py
	```

## Código Fuente
	```python
def saludar():
	print("Hola, Git!")

if __name__ == "__main__":
	saludar()
```
## Tecnologías

* **Python 3** - Lenguaje de programación.
